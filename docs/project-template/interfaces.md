# Electrical and firmware interfaces

Authoritative pin/part truth: KiCad schematic + approved datasheets.
Reviewed mapping: `hardware/interfaces/pinmap.csv`.

Document per connector: connector ref, orientation, pin #, signal, voltage,
current, input impedance, boot/reset state, protocol, ESD, grounds, mating part,
external power source and human-safe assembly rules.

Record MCU pin mux / alternate function and any reserved debugger pins.
