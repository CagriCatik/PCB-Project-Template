# Component lifecycle

`bom_master.csv` is a **reviewed sourcing supplement**, NOT an independent
replacement for the BOM exported from KiCad. Reconcile reference designators,
part numbers, package, alternate options, lifecycle and quantities against the
actual schematic at each release.

Datasheets and 3D files: cite source, vendor, revision, retrieval date, licence
and hash. If redistribution is not permitted, store URL plus metadata only.
